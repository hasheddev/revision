CTAS & TEMP

A Table is a strucured collection of data, similar to a spreadsheet or grid(Excel) with column and rows, Cells are a single piece of data and are stored as database files on the disk.

We have permanent and temporary tables
Permanent tables last aslong as they are not dropped. Can be created with CREATE TABLE and CREATE TABLE AS SELECT(CTAS)
Create/Insert: Creates table then inserts data into the table
CTAS: Retrieve data from a atble and create a brand new table from the query shring same structure, it needs a database table to exist

CTAS VS VIEWS
Views store query but Ctas executes query and result is in a new table
Views use two queries before returning result while the new ctas table is queried once making views slower
Views maintain updated view of Original table while Ctas data differ fom the original table if the original is updated making it harder to maintain
