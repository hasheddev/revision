Used to aggregate data side by side with column of main query

SELECT Column1,
    (SELECT column FROM table WHERE condition)
FROM table1

Only Scalar subqueries are allowed(only one value is allowed)

Show product IDS, product names, prices and total number of orders

SELECT
	ProductID,
	Product,
	Price,
	(SELECT COUNT(*) FROM Sales.Orders) TotalOrders
FROM Sales.Products
