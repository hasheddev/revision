Used for complex filtering logic and makes query more flexible and dynamic

Operators:
- Comparison: <, >, =, !=, >=, <=
- Logical: IN, ANY, ALL, EXISTS

Comparison operators are used to compare two values
SELECT column, ...
FROM table
WHERE column = (SELECT column FROM table2 WHERE condition)

COMPARISON: The subquery must be a scaler subquery for comparison operators

Find products that have a price higher that the average price of all products

SELECT
 ProductID,
 Price
FROM Sales.Products
WHERE Price > (SELECT AVG(Price) FROM Sales.Products)

ANY: Check is condition is true for any value in a list
Use comparison followed by ANY  WHERE  SAME FOR ALL E.g < ANY (1, 2, 3)

ALL: Checks if a value matches EVERY values within a list

EXISTS
Is used to check if a table row exist if any value is returned

Below is a Correlated subquery using exists

Select column, ...
From tabel2
Where EXISTS (SELECT 1 FROM Table1WHERE Table1.Id = Table2.Id)

Show all orders made by cusytomers in Germany


SELECT *
FROM Sales.Orders o WHERE  EXISTS 
	(SELECT * FROM Sales.Customers c WHERE Country = 'Germany' AND o.CustomerID = c.CustomerID)

* can be 1 or any value here as it is faster
