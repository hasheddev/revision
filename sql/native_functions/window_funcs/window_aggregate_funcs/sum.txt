Returns sum of all values within a window

SUM(Sales) OVER (PARTITION BY Product)
It Ignores NULL in calculation and accetps only Integers.
If all values are NULL it returns NULL

Use cases

- Overall analysis
- Group analysis

SELECT
	OrderID,
	OrderDate,
	ProductID,
	SUM(Sales) OVER () TotaSales,
	SUM(Sales) OVER (PARTITION BY ProductID) SalesByProduct
From Sales.Orders
