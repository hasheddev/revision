SELECT

  Count(*) TotalOrders
From Sales.Orders

This fails because it creates a fundamental contradiction for SQL. You are asking it to do two completely opposite things at the exact same time:

ProductID asks SQL to show you every single individual row in the table.

COUNT(*) asks SQL to collapse all those rows into one single summary number (the grand total of all orders).

Without a GROUP BY clause, SQL looks at this and doesn't know what you want. It can't show you a detailed list of individual products and a single total count in the same result set.

-- What you are asking SQL to build:

| ProductID | TotalOrders |
| :-------- | :---------- |
| 101       |             |
| 102       |     5       |  <-- SQL doesn't know how to align 
| 101       |             |      one total across five separate rows.
| 103       |             |
| 102       |             |
