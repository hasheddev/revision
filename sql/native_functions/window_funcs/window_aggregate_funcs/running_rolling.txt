RUNNING TOTAL AND ROLLING TOTAL

Tracking current sales with target sales and providing insights into historical pattern

They aggregate a sequence of numbers and the aggregation updates when a new member is added (analysis over time)

Running Total: Aggregates from beginning up to current with no data missing

Rolling total: Aggregate all values within a fixed time window e.g 30 days,. As new data is added, the oldest is dropped giving a shifting.rolling time window

RUNNING TOTAL:
SUM(SALES) OVER (ORDER BY MONTH) //Default ROWS BETWEEN UNBOUNDED PRECEEDING AND CURRENT ROW    frame default when order by is sued and frame is not given

ROLLING TOTAL
SUM(SALES) OVER (ORDER BY MONTH ROWS BETWEEN 2 PRECEEDING AND CURRENT ROW)

MOVING AVERAGE
SELECT
     OrderID,
     ProductID,
     OrderDate,
     Sales,
      AVG(Sales) OVER (PARTITION BY ProductID) AvgByProduct,
     AVG(Sales) OVER (PARTITION BY ProductID ORDER BY OrderDate ASC) MovingAvg
FROM Sales.Orders
