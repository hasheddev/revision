FIRST_VALUE allows access to first row within a window
LAST_VALUE allows access to last row within a window

FIRST_VALUE/LAST_VALUE(Sales) OVER(ORDER BY Month)
applies RANGE BETWEEN UNBOUNDED PRECEEDING AND CURRENT ROW

The default frame definition gives right answer for FIRST_VALUE but has to be cutomized for LAST_VALUE using

ROWS BETWEEN CURRENT ROW AND UNBOUNDED FOLLOWING

find lowest and highest sales for each product

SELECT
	OrderID,
	ProductID,
	Sales,
	FIRST_VALUE(Sales) OVER(PARTITION BY ProductID ORDER BY Sales) lowestSales
FROM Sales.Orders
