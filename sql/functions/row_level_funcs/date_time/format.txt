FORMAT: FORMAT(value, format, [,culture])

value can be date or number, format = new format for value, culture = exmaple value in stle of specific country or region(optional)

SELECT FORMAT(1234.56, 'C', 'fr-FR');  France separes thounsands using space and comma for decimals
