DATEADD: add or subtract a specific time interval to date, months, days and years, it can also subtract if negative number is used

DATEADD(part, interval, date)

part = months, date, year
interval = amount of part to add

date =date to manipulate

DATEADD(year, 2, OrderDate)
DATEADD(month, -2, OrderDate)
DATEADD(day, -10, OrderDate)

SELECT CreationTime,
DATEADD(year, 2, CreationTime) As year_added,
DATEADD(month, -2, CreationTime) As months_prior
FROM Sales.Orders

Date diff find difference between two dates

DATEDIFF(part, start_date, end_date)

Result = enddate - startdate   can be negative

Calculate age of employees

SELECT EmployeeID, BirthDate,
DATEDIFF(year, BirthDate, GETDATE()) AS Age
FROM Sales.Employees

Find average shipping duration in days for each month
SELECT MONTH(OrderDate) AS ShipMonth,
AVG(DATEDIFF(day, orderDate, shipDate)) AveShipDayPerMonth
FROM Sales.Orders
GROUP BY MONTH(OrderDate)

2	7
3	5

SELECT OrderDate AS CurrenOrderDate,
LAG(OrderDate) OVER (ORDER BY OrderDate) as PreviousOrderdate,
DATEDIFF(day, LAG(OrderDate) OVER (ORDER BY OrderDate), orderDate) NrOfDays
FROM Sales.Orders
