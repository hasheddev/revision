ISNULL, COALESCE - These functions are used to ensure correct aggregation values as functions like SUM, AVG and others other than COUNT ignore null value so n a three roe table AVG will be / 2 and not 3

If null is included we get NULL as the result of the function call  replacing NULL with a default makes the function use / 3 for avg
